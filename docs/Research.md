# Project: Adaptive Documentation Course Creator  
*Interactive knowledge graph-driven learning platform for technical documentation*

***

## **Vision & Overview**

Build an AI-powered platform that crawls entire documentation sites, intelligently extracts and organizes knowledge into a micro-article knowledge graph, and delivers **short, interconnected learning modules** in a swipeable feed (à la TikTok Shorts). The app is **adaptive:** it responds in real-time to user preferences, progression, and actions (skipping, deep-diving), and constantly adjusts the learning path, leveraging long-term memory and graph traversal algorithms to optimize mastery.

***

## **Core User Experience & Features**

- **Onboarding:**  
  Users set their learning preferences, existing knowledge, and goals (e.g., “technical overviews” vs. “in-depth analysis”).
- **Shorts-Style Article Feed:**  
  Each “article” (node) is short (1–2 paragraphs), focused, and has its own URL. Users scroll to browse, double-tap to mark complete, and access side actions:
  - Go in-depth (jump to a deeper, related concept)
  - View related articles/comments
  - Bookmark/save
  - Quiz on material so far
- **Intelligent Traversal:**  
  The platform generates and adapts a recommended path through the knowledge graph based on both initial onboarding and ongoing real-time user behavior, ensuring relevant, non-redundant, and engaging progression.
- **Course Management:**  
  Users can view their active courses, create new ones from any documentation link, and track detailed progress.

***

## **Backend Tech Stack & Architecture**

- **Web Scraping and Content Extraction**
  - Use Firecrawl or Crawl4AI to deeply crawl documentation sites and extract all textual content, supporting JS-heavy and multi-page docs.
- **Topic Extraction & Taxonomy Generation**
  - Cohere API (Topic Extraction): Segment crawled content into meaningful topics, subtopics, and entities; build hierarchical taxonomy and deduplicate semantically similar concepts.
  - Use Gemini/LLMs if finer-grained semantic structuring is required.
- **Knowledge Graph Creation**
  - Construct graph nodes (articles) for each concept, article, and subtopic.
  - Edges encode relationships: prerequisite, related, belongs-to, alternative.
  - Each edge stores weight (strength of relation), type, and metadata for adaptivity.
  - Use Neo4j (graph DB) to persist structure and enable advanced traversal/analysis.
- **Supermemory RAG Integration**
  - Store all articles, user actions, preferences, and feedback in Supermemory—a persistent, adaptive vector/graph memory system.
  - Index content for retrieval, semantic search, and long-term learning tracking.
- **AI/LLM Pipeline**
  - Use Gemini and/or Langchain.js agents for:
    - Chunking large docs
    - Generating article text and summaries for graph nodes
    - Adaptive question/quiz generation
    - Path optimization and traversal logic
    - Personalized recommendations
- **API Layer**
  - Next.js backend (API routes) to serve content, user data, progress, course management, and handle integration with Neo4j/Supermemory/Cohere/Gemini.

- Onboarding, settings dialog, user detail/progress, course tabs, shorts-style article feed with all required interactive elements.
- SEO, security, mobile responsiveness, accessibility all prioritized.

## **End-to-End System Flow**

1. **User begins onboarding.**
   - Sets preferences, initial knowledge, and learning goals; skipped if returning user.
2. **User provides documentation link.**
   - Backend crawls all pages, extracts and segments content.
3. **Topic extraction (Cohere API/Gemini).**
   - Build taxonomy and deduplicated knowledge graph.
4. **Populate knowledge graph (Neo4j).**
   - Nodes = short articles (1–2 paragraphs), URLs, metadata, relationships.
   - Edges encode prerequisite, related, depth, and semantic overlap.
5. **Store articles/content and graph in Supermemory.**
   - Track user progression, history, and adaptive feedback.
6. **Front-end displays adaptive shorts-style feed.**
   - Feed generated by traversing the graph based on “main path” tailored to user profile.
   - User actions (skip, go deep, quiz, bookmark) are logged and adapt traversal in real-time (without changing the base graph).
   - Path adapts: nodes are reordered, deep nodes surfaced, redundant nodes pruned—all temp, based on user goals.
7. **Feedback loop and analytics.**
   - App tracks skips/completions, time-on-node, quizzes, bookmarks.
   - Live updates to path and optional suggested content.
   - Supermemory continuously updates the adaptive model per user.

## **Research-backed Design Principles**

- **Microlearning:**  
  Bite-sized articles retain attention, enable rapid review, and facilitate “just-in-time” conceptual mastery.
- **Knowledge Graphs:**  
  Represent content as a web, not a linear course—supports nonlinear discovery, personalized branching, and visual path mapping.
- **Taxonomy & Relationship Extraction:**  
  Leverage APIs/AI to ensure articles are deduplicated, semantically linked, and presented in optimal order.
- **Adaptive Traversal Algorithms:**  
  Use dynamic/weighted traversals (BFS, DFS, heuristic, GraphRAG, PolyG, etc.) for course path, always context-aware and user-personalized.
- **Persistent Memory:**  
  Supermemory graph enables lifelong learning, tracking, personalized reminders, and evolving content recommendations.
